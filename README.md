# Глобус

Пошаговая стратегия на листе в клетку по мотивам школьной игры 80-х: экономика, танки, авиация, флот и колонии.

**Играть:** откройте `index.html` в браузере. Работает без интернета, шрифты лежат в папке `fonts`.

- 2–4 игрока; каждого можно сделать человеком или компьютером, все играют за одним экраном.
- Правила — кнопка «Правила» в игре.
- Что сделано и что осталось — в файле [NOTES.md](NOTES.md).

## Шрифты
