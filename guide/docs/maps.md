# Карты: откуда брать и как показывать

Состояние на 9 ноября 2026. Цены и условия меняются, перед запуском их надо перепроверить
по ссылкам в конце. В разделе «Что проверено» сказано, какие факты откуда.

## Вывод

Для прототипа: **MapLibre Native + открытые векторные тайлы OpenStreetMap**.

- Карта берётся одной строкой настройки (адрес стиля) у бесплатного хостинга OpenFreeMap, без ключа.
- Запасной и офлайн-вариант уже есть: готовый файл карты Цюриха и окрестностей, 32 МБ.
- Наша база мест собрана из открытых источников, её можно хранить, кэшировать и показывать на любой карте.
- Платы за показы карты нет, привязки к поставщику нет: сменить источник тайлов значит сменить адрес стиля.

Google Maps как карта тоже подходит и в нативном Android бесплатна. Но данные Google Places
с нашим подходом «своя база мест» несовместимы: их нельзя хранить и нельзя показывать на чужой карте.

## Как устроена карта в приложении

Карта состоит из трёх независимых частей:

1. **Движок** в приложении рисует карту и обрабатывает жесты (MapLibre, Google Maps SDK, Mapbox SDK).
2. **Подложка**: улицы, здания, вода, подписи. Приходит с сервера тайлами или лежит файлом на устройстве.
3. **Наши места**: точки поверх подложки. Их приложение получает от нашего бэкенда.

Пункты 1 и 2 выбираются здесь. Пункт 3 одинаков при любом выборе.

## Варианты

| Вариант | Цена | Офлайн | Главное ограничение |
|---|---|---|---|
| MapLibre + OpenFreeMap | Бесплатно, без ключа | Нет (нужен интернет) | Сервис «как есть», живёт на пожертвования |
| MapLibre + свой файл PMTiles | Только хранение и трафик | Да | Файл и стиль обновляем сами |
| MapLibre + swisstopo | Бесплатно | Не выяснено | Только Швейцария; условия для коммерции неясны |
| Google Maps SDK | Бесплатно в нативном Android | Нет | Условия Google на данные; карты с Map ID платные |
| Mapbox Maps SDK | 25 000 активных пользователей в месяц бесплатно | Да | Закрытый SDK, нет потолка расходов |
| MapTiler Cloud | Бесплатный план некоммерческий | Да | Для коммерции от ~$30 в месяц |
| osmdroid | Бесплатно | Да | Заброшен с 20.11.2024, не брать |

### MapLibre Native

Открытый движок векторных карт для Android и iOS. Сам данных не содержит, ему нужен адрес стиля.

- **Версия с поддержкой PMTiles:** начиная с Android 11.7.0.
- **Compose:** есть обёртка MapLibre Compose (Android, iOS, десктоп, веб). Версия 0.12.x, API ещё меняется
  между минорными версиями. Запасной путь: обычный `MapView` внутри `AndroidView`.
- **Наши места:** источник GeoJSON и слой значков; кластеризация точек встроена в движок.

### Подложка: OpenFreeMap

Публичный сервер векторных тайлов OSM. Регистрации, ключа и лимитов запросов нет, коммерческое
использование разрешено с указанием авторства. Адрес стиля: `https://tiles.openfreemap.org/styles/liberty`
(есть также `bright` и `positron`).

Гарантий доступности нет. Проект открытый, тот же сервер можно развернуть у себя.

### Подложка: свой файл PMTiles

PMTiles — вся карта региона в одном файле. Его можно положить на любое статическое хранилище
или прямо на устройство; отдельный сервер тайлов не нужен.

- **Готовый файл Цюриха:** `https://download.bbbike.org/osm/bbbike/Zuerich/Zuerich.osm.pmtiles-shortbread.zip`,
  32,3 МБ, обновлён 8 ноября 2026. Схема слоёв Shortbread, под неё нужен совместимый стиль (например, VersaTiles).
- **Подключение в MapLibre Android:** `pmtiles://https://…` для файла в сети, `pmtiles://file://…` для файла на устройстве.
- **Ограничение:** для источников PMTiles не работают встроенные офлайн-пакеты и кэш MapLibre.
  Офлайн получается только скачиванием файла целиком.
- **Другие города:** BBBike публикует такие же выгрузки для пары сотен городов; для остальных файл
  вырезается из планеты утилитой `pmtiles extract`.

### Подложка: swisstopo

Государственная карта Швейцарии, векторные тайлы в формате MapLibre, очень подробная.
Адрес стиля: `https://vectortiles.geo.admin.ch/styles/ch.swisstopo.lightbasemap.vt/style.json`.
Обязательная подпись: «© swisstopo».

Для Цюриха это самая красивая подложка, но за границей Швейцарии она не годится. На opendata.swiss
у Light Base Map указано «коммерческое использование с разрешения», а у Base Map «открытое использование» —
перед коммерческим запуском надо выяснить.

### Google Maps SDK for Android

- **Цена карты:** по документации Google, мобильное использование Maps SDK for Android не ограничено и бесплатно.
- **Исключение:** карта, загруженная с Map ID (облачные стили), тарифицируется как Dynamic Maps:
  10 000 загрузок в месяц бесплатно, дальше $7 за 1000.
- **Compose:** официальная библиотека `maps-compose`.
- **Офлайна для разработчиков нет.**

Наши собственные точки на карте Google показывать можно. Ограничения касаются данных Google Places:

- содержимое Places нельзя использовать вместе с картой не от Google;
- хранить бессрочно можно только идентификатор места, координаты не дольше 30 дней;
- цены Places API (New): Nearby Search Pro $32 за 1000 после 5000 бесплатных в месяц,
  Place Details Essentials $5 за 1000 после 10 000 бесплатных.

Из этого следует: если когда-нибудь понадобятся рейтинги и часы работы от Google, придётся
показывать их на карте Google и запрашивать при каждом открытии карточки.

### Mapbox Maps SDK

Закрытый SDK с хорошими стилями и офлайном. Оплата по числу активных пользователей в месяц:
по сторонним источникам 25 000 бесплатно, дальше около $4 за 1000. Жёсткого потолка расходов нет.
MapLibre — открытое ответвление старой версии Mapbox, для наших задач его достаточно.

## Что ещё понадобится от карты

- **Подпись авторства на карте** обязательна: «© OpenStreetMap contributors» для любой подложки на данных OSM.
- **Маршрут до места:** в прототипе проще открыть внешнее приложение карт ссылкой с координатами.
  Свой маршрутизатор и расписание транспорта — отдельная задача, не исследовалась.
- **Местоположение пользователя:** точку на карте рисует сам движок; от приложения нужно разрешение на геолокацию.

- **Проверено из этой сессии напрямую:** файлы BBBike, их размеры и даты.
- **Официальные страницы, прочитанные через поиск:** таблица цен Google (строки Maps SDK и Dynamic Maps),
  руководство MapLibre по PMTiles, документация swisstopo.
- **Сторонние источники:** условия OpenFreeMap, цены Mapbox и MapTiler, цены Places API.
- **Не подтверждено:** текущая редакция условий Google (версии различаются), условия swisstopo для коммерции,
  нужна ли карте Google Map ID для нужных нам возможностей.
