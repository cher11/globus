# guide: городской гид

Папка с материалами отдельного проекта: мобильного приложения-гида по городам.
С игрой в корне репозитория она не связана. Пилотный город — Цюрих.

Кода приложения здесь пока нет. Есть проект, справка по картам и собранная база мест.

## Документы

- [`docs/architecture.md`](docs/architecture.md) — архитектура: приложение, бэкенд, модель данных,
  конвейер города, задачи ИИ, API, стоимость, план по шагам. Начинать с раздела «Коротко».
- [`docs/maps.md`](docs/maps.md) — откуда брать карту и как её показывать.
- [`data/zurich/README.md`](data/zurich/README.md) — база мест Цюриха: источники, схема,
  качество слияния, покрытие, известные проблемы.

## Данные и скрипты

- `data/zurich/places.ndjson` — 12 861 место, одна строка JSON на место.
- `data/zurich/stats.json`, `merge_report.json`, `sources.json` — измеренные показатели.
- `data/zurich/context/` — проза Wikivoyage о городе, контекст для ИИ.
- `data/zurich/raw/` — данные источников в том виде, как получены.
- `tools/collect/` — скрипты сбора и слияния; порядок запуска описан в `data/zurich/README.md`.

## Пакет города и просмотрщик (шаг M0)

Сборка, по порядку (из папки `guide/`):

```
python3 tools/pack/export_pack.py zurich 1     # dist/zurich/zurich-v1.sqlite(.gz), manifest.json
python3 tools/pack/build_basemap.py zurich     # dist/zurich/basemap.json — своя подложка из выгрузки OSM
python3 tools/pack/build_viewer.py zurich 1 <путь к leaflet.css>   # dist/zurich/viewer.html
```

- **Пакет** — SQLite по схеме из раздела 8 архитектуры, версия схемы 0. Таблицы и столбцы
  целевые, но поля, которые выводит шаг M1 (`kind`, `rank`, `visibility`, `status`,
  `parent_pid`), пока пустые, а `pid` — идентификатор слияния, он может меняться между сборками.
  Лицензии записаны у каждого текста, картинки и источника; ничего не отфильтровано.
- **Просмотрщик** — одна страница: карта и топ-списки 4 556 основных мест по группам и районам,
  отметки «хорошо / мусор / не та категория / дубль / закрыто». Страница не может грузить чужие
  тайлы, поэтому подложка своя: вода, зелень, дороги, железная дорога, границы районов.
  CSS Leaflet берётся из npm-пакета `leaflet@1.9.4` (`dist/leaflet.css`).
- Папка `dist/` в git не попадает: всё в ней пересобирается из `data/`.
