# Тесты

Проверяют `../index.html` в headless Chromium через Playwright.

```
cd tests
npm install            # ставит playwright; браузер: npx playwright install chromium
npm test               # правила и интерфейс (rules.test.js)
node net.test.js       # игра по сети: два браузера, поддельные Telegram Bot API и GitHub API
node record.test.js    # запись партии: сохранить, воспроизвести, поле совпадает
node codec.test.js     # своё сжатие (для Safari до 16.4) и браузерное читают друг друга
node ai-habits.test.js # привычки компьютера, замеченные в игре: танк не жжёт клетки у своей базы, самолёт не меняется на человека большой колонии, пушка не встаёт под чужой выстрел
node user-games.test.js [other.html]  # позиции из настоящих партий (записи в games/): компьютер не повторяет ошибку
node ai-tactics.test.js            # тактические позиции для компьютера (ai-tactics.test.js ../old.html — для другой версии)
node ai-batch.js 2 6 400   # партии «компьютер против компьютера»: игроков, партий, лимит ходов
node ai-duel.js 12 300 new rush            # статистика компьютера: начало партии, потери, время на ход
node ai-duel.js 12 300 new enc             # против танковой осады: сколько раз компьютер выбыл запертым
node ai-duel.js 12 300 new lander          # против высадки: человек с линкора у базы компьютера строит танки
node ai-duel.js 12 300 new ../old.html     # компьютер против компьютера из другой версии игры
node ai-duel.js 12 300 new ../old.html 3 1000   # то же, 3 вкладки, на обдумывание хода до 1000 мс (по умолчанию 80)
```

`ai-duel.js` играет посеянные партии (при разных соперниках — с обеих сторон) и печатает для каждой стороны: на каком ходу пятое поле, первый завод и урожай 30, сколько лишних полей, сколько юнитов погибло сразу после хода под чужой огонь, игру на море (построено линкоров, посажено и высажено людей, погружено зениток), сколько раз сторона выбыла, не имея ходов (STUCK), время на ход. Компьютер проверяет свои лучшие по оценке ходы на шаг вперёд: разыгрывает каждый на копии партии, ищет лучший ответ противника (ход и выстрел) и меняет выбранный ход, только если другой тактически заметно лучше. Думает не дольше бюджета `AI_LOOK.ms` (в игре — 1000 мс, обычно хватает 10–60 мс; в `ai-duel.js` — шестой аргумент, по умолчанию 80 мс). Сценарные соперники для него: `rusher.js` — ранний налёт самолётами на заводы (`rush` — осторожный, `rush1` — лезет под зенитки); `encircler.js` (`enc`) — танки, которые выжигают клетки вокруг чужих людей, пока тем некуда строить; `lander.js` (`lander`) — план человека, который обыграл компьютер: обычная экономика, затем линкор высаживает человека на берег у чужой базы, тот строит танки, и они давят поля, заводы и людей и выжигают клетки вокруг них. Его техника ходит, как человек: на клетку, откуда ударит следующим ходом, не под нацеленные пушки, и стреляет после хода, если так выгоднее. Без морского пути танки идут из дома по суше.

`ai-tactics.test.js` строит на пустой карте позиции, где правильный ход ясен, играет за компьютер один ход (так же, как `aiTurn`) и проверяет через `aiReply`, что противник ответным ходом не возьмёт лишнего: самолёт не садится на завод там, куда враг может сесть на человека и тут же выстрелить по самолёту; линкор уходит из такой зоны; танк, заслоняющий двух последних людей от вражеского танка, не уезжает; последнего человека заслоняют пушкой на пути танка; выстрел идёт по танку, который раздавит двух людей, а не по более дорогому линкору. Три позиции разыгрываются на три круга против `lander.js` и проверяют, сколько компьютер в среднем потерял за четыре попытки (по цене `aiWorth`, порог 60): вражеский танк у базы; высаженный у базы человек, который строит танк; позиция из настоящей партии против высадки (карта той партии, ход 34): танк захватчика стоит у базы вне пушек и следующим ходом въезжает давить. Прежняя версия теряет в двух последних 73 и 303, новая — в среднем 26 и 28. С путём к другой версии игры проверяет её компьютер на движке этой страницы.

В игре есть отладочный доступ `window.__globus` (запуск партии, мгновенный режим без анимаций, функции движка и компьютера) — тесты работают через него.
