# Тесты

Проверяют `../index.html` в headless Chromium через Playwright.

```
cd tests
npm install            # ставит playwright; браузер: npx playwright install chromium
npm test               # правила и интерфейс (rules.test.js)
node net.test.js       # игра по сети: два браузера и поддельный Telegram Bot API
node record.test.js    # запись партии: сохранить, воспроизвести, поле совпадает
node ai-tactics.test.js            # тактические позиции для компьютера (ai-tactics.test.js ../old.html — для другой версии)
node ai-batch.js 2 6 400   # партии «компьютер против компьютера»: игроков, партий, лимит ходов
node ai-duel.js 12 300 new rush            # статистика компьютера: начало партии, потери, время на ход
node ai-duel.js 12 300 new enc             # против танковой осады: сколько раз компьютер выбыл запертым
node ai-duel.js 12 300 new ../old.html     # компьютер против компьютера из другой версии игры
node ai-duel.js 12 300 new ../old.html 3 1000   # то же, 3 вкладки, на обдумывание хода до 1000 мс (по умолчанию 80)
```

`ai-duel.js` играет посеянные партии (при разных соперниках — с обеих сторон) и печатает для каждой стороны: на каком ходу пятое поле, первый завод и урожай 30, сколько лишних полей, сколько юнитов погибло сразу после хода под чужой огонь, игру на море (построено линкоров, посажено и высажено людей, погружено зениток), сколько раз сторона выбыла, не имея ходов (STUCK), время на ход. Компьютер проверяет свои лучшие по оценке ходы на шаг вперёд: разыгрывает каждый на копии партии, ищет лучший ответ противника (ход и выстрел) и меняет выбранный ход, только если другой тактически заметно лучше. Думает не дольше бюджета `AI_LOOK.ms` (в игре — 1000 мс, обычно хватает 10–60 мс; в `ai-duel.js` — шестой аргумент, по умолчанию 80 мс). Сценарные соперники для него: `rusher.js` — ранний налёт самолётами на заводы (`rush` — осторожный, `rush1` — лезет под зенитки); `encircler.js` (`enc`) — танки, которые выжигают клетки вокруг чужих людей, пока тем некуда строить.

`ai-tactics.test.js` строит на пустой карте позиции, где правильный ход ясен, играет за компьютер один ход (так же, как `aiTurn`) и проверяет через `aiReply`, что противник ответным ходом не возьмёт лишнего: самолёт не садится на завод там, куда враг может сесть на человека и тут же выстрелить по самолёту; линкор уходит из такой зоны; танк, заслоняющий двух последних людей от вражеского танка, не уезжает; последнего человека заслоняют пушкой на пути танка; выстрел идёт по танку, который раздавит двух людей, а не по более дорогому линкору. С путём к другой версии игры проверяет её компьютер на движке этой страницы.

В игре есть отладочный доступ `window.__globus` (запуск партии, мгновенный режим без анимаций, функции движка и компьютера) — тесты работают через него.
